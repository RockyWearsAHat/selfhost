LAMP LEGEND

OK: device is responding, on and available.
WARN: something needs attention but is not broken — a device converging, or stale commands waiting.
BAD: the hub refused the command, or the device stopped answering.
IDLE: device is off, or the page has no report yet.
PENDING: a command is in flight to the device, still waiting for confirmation.
